# 03 - 依赖与构建配置

## TKUISDK_iOS.podspec（发布配置）

| 配置项 | 值 | 说明 |
| --- | --- | --- |
| `s.name` | `TKUISDK_iOS` | pod 名 |
| `s.version` | `4.18.5.4` | 当前版本，发版前修改，与 git tag 一致 |
| `s.source` | `https://github.com/Talk-Cloud/TKUISDK_iOS.git` + `:tag` | 按 tag 拉取产物 |
| `s.ios.deployment_target` | `12.0` | 最低 iOS 版本 |
| `s.ios.vendored_frameworks` | `TKUISDK_iOS/Frameworks/*.framework` | 分发 6 个预编译 Framework |
| `s.static_framework` | `true` | 静态化开关（注意：上方注释提示与动态 vendored framework 可能冲突，改动前先在 Example 验证） |
| `s.pod_target_xcconfig` | `VALID_ARCHS = x86_64 armv7 arm64 arm64e` | 架构白名单 |
| `s.license` | MIT（`LICENSE` 文件） | |
| `s.dependency` | 全部注释 | SDK 不向下游传递三方依赖，lottie-ios / Masonry / SDWebImage 由集成方自行引入 |

资源约定：资源内嵌在各 Framework 的 bundle 中，未声明 `s.resources`。

## Example/Podfile（示例工程依赖）

```ruby
use_frameworks!
platform :ios, '12.0'

target 'TKUISDK_iOS_Example' do
  pod 'TKUISDK_iOS', :path => '../'   # 本地引用仓库根目录 podspec
  pod 'TKScreenShareService'
  pod 'Masonry'
  pod 'Bugly', '2.5.0'
  pod 'UMCommon', '7.2.5'
  pod 'UMShare/UI', '6.10.1'
  pod 'UMShare/Social/WeChat', '6.10.1'
  pod 'UMShare/Social/QQ', '6.10.1'
  pod 'UMShare/Social/Sina', '6.10.1'
  pod 'MicrosoftCognitiveServicesSpeech-iOS'
end

target 'TKScreenRecorder' do
  pod 'TKScreenShareService'
end
```

- Bugly / UMCommon / UMShare 锁定精确版本；其余未指定版本。
- 除 `TKUISDK_iOS`（本地 path）外，依赖均来自 CocoaPods trunk。

## 锁定文件

| 文件 | 作用 |
| --- | --- |
| `Example/Podfile.lock` | 完整依赖树、SPEC CHECKSUM、COCOAPODS 版本（1.16.2），保证构建可复现 |
| `Example/Pods/Manifest.lock` | Pods 目录快照，与 Podfile.lock 对应，不一致时 `pod install` 会报错提示 |
