# 02 - 示例工程目录（Example/）

示例工程用于本地验证 SDK 集成，通过 `:path => '../'` 引用仓库根目录的 podspec。日常开发打开 `TKUISDK_iOS.xcworkspace`。

## 目录结构

```
Example/
├── TKUISDK_iOS/            # 示例 App 主 Target（TKUISDK_iOS_Example）
├── TKScreenRecorder/       # 屏幕共享 Extension Target
├── Tests/                  # 单元测试 Target
├── TKUISDK_iOS.xcodeproj/
├── TKUISDK_iOS.xcworkspace/  # 日常开发打开此文件
├── Podfile                 # 依赖声明，本地路径引用 SDK
├── Podfile.lock            # 依赖版本锁定
├── Pods/                   # pod install 产物（三方依赖源码/二进制）
├── build/                  # 构建产物
└── TKUISDK_iOS_Example.entitlements
```

## TKUISDK_iOS/（示例 App 主 Target）

```
TKUISDK_iOS/
├── main.m / AppDelegate.h/.m           # 应用入口
├── ViewController.h/.m                 # 主页面
├── TKLoginViewController.h/.m          # 登录演示页
├── TKJoinClassViewController.h/.m      # 进教室演示页
├── TKDemoEnumHeader.h                  # Demo 枚举定义
├── View/                               # 演示 UI 组件（登录、回放、隐私协议等）
│   ├── TKLoginAlert / TKLoginInputView / TKLoginPermissionView / TKLoginSettingView
│   ├── TKChoseRoleView / TKPassWordHelpView / TKPermissonCell
│   ├── TKPlaybackView / TKPlaybackCell / TKPlaybackTimeView
│   ├── TKPrivacyView / TKServiceAndPrivacyAlterView / TKSPContentView
│   └── TKAboutUSView
├── PluginClass/                        # 插件示例
│   ├── TK_Share/                       # 友盟分享插件
│   └── TK_Speech/                      # 微软语音插件
├── TKScreenRecorder/                   # 屏幕录制 Extension 源码（SampleHandler）
├── Images.xcassets/                    # 示例 App 图片（AppIcon、login/ 等）
├── Base.lproj/                         # LaunchScreen / Main storyboard
├── en.lproj/ fr.lproj/ ja.lproj/ ko.lproj/ zh-Hans.lproj/ zh-Hant.lproj/
│                                       # 多语言 Localizable.strings / InfoPlist.strings
├── TKUISDK_iOS-Info.plist
└── TKUISDK_iOS-Prefix.pch
```

## Pods/（三方依赖，pod install 生成）

| 目录 | 说明 |
| --- | --- |
| `Masonry/` | 自动布局 |
| `SDWebImage/` | 图片加载 |
| `lottie-ios/` | 动效 |
| `Bugly/` | 崩溃统计 |
| `UMCommon/` `UMDevice/` `UMShare/` | 友盟统计与分享 |
| `MicrosoftCognitiveServicesSpeech-iOS/` | 微软实时语音 |
| `TKScreenShareService/` | 屏幕共享服务 |
| `Local Podspecs/` | 本地 podspec |
| `Target Support Files/` | CocoaPods 生成的构建配置 |
| `Headers/` `Pods.xcodeproj/` `Manifest.lock` | CocoaPods 产物 |

## 验证方式

替换 `TKUISDK_iOS/Frameworks/` 产物后，在 Example 目录执行 `pod install`，打开 workspace 编译运行即可验证集成。
